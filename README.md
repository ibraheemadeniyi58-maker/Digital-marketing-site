# Ibraheem Adeniyi — Personal Digital Marketing Portfolio

Responsive one-page personal portfolio for digital marketing, web design, website development and digital strategy.

## Sections
- Introduction and personal positioning
- About, skills and platforms
- Services
- Portfolio placeholders for **verified** case studies
- Client-facing working approach
- Contact call to action

## Customize before sharing with buyers
1. Replace the three clearly labeled portfolio placeholders with screenshots and accurate descriptions of work you have permission to display.
2. Add a confirmed business email, contact form or booking link.
3. Add authentic testimonials only with permission.
4. Add a real professional portrait (with consent) and any confirmed certifications.
5. Review all service claims for accuracy.

## Deployment with GitHub Pages
Repo > Settings > Pages > Deploy from a branch > main / root.
Then use the displayed Pages URL.

Static HTML, CSS and JavaScript. No build process or dependencies. Google Fonts requires network access.
